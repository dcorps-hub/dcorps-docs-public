> Scope: Historical summary of a superseded DevCo path.

Status note: This is not an executed contract and does not constitute legal advice. It reflects an older structure draft that is no longer the current intended path. The working structure is foundation-first pre-genesis rather than BVI DevCo-first.

---

## 1. Historical path only

- Earlier drafts contemplated a BVI-based development corporation as the main engineering and launch vehicle.
- That is no longer the current intended structure.
- Use [docs/legal/STRUCTURE_PATH.md](/legal/STRUCTURE_PATH) as the current summary.

---

## 2. Current replacement posture

- The intended structure is direct foundation stewardship in Abu Dhabi / ADGM before genesis.
- Engineering may still be performed by service providers under contract.
- IP stewardship should sit under the foundation before genesis rather than moving there later from a DevCo.

---

## 3. Change control

If a DevCo path is revived later, it should be documented as a new current-structure proposal rather than inferred from this historical page.
